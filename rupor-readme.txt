РУПОР — видеовстречи и голосовая связь прямо в браузере
=========================================================

Что это такое
-------------
Рупор — прогрессивное веб-приложение (PWA) для видеозвонков,
голосовой связи и демонстрации экрана. Никакой регистрации на
сторонних сервисах, никаких серверов кроме публичных MQTT-брокеров
для сигнализации. Все данные аккаунта хранятся только в браузере.


Как запустить
-------------
Откройте rupor.html в любом современном браузере (Chrome 110+,
Firefox 110+, Edge 110+). Файл полностью самодостаточен — интернет
нужен только для MQTT-брокеров и STUN-серверов.

Для установки как приложение нажмите иконку «Установить» в адресной
строке Chrome или Edge.


Аккаунты
--------
Аккаунты хранятся только в localStorage этого браузера.
Ни пароль, ни личные данные никуда не передаются.

  Создание: введите имя пользователя и пароль (минимум 6 символов).
  Вход:     те же имя и пароль — они всегда дают один и тот же ID,
            поэтому с другого устройства можно войти в ту же группу.
  Выход:    кнопка «Выйти» в панели аккаунта.


Группы
------
Группы используют MQTT для хранения общего списка участников.

  Создать группу: нажмите «Создать группу», введите название.
  Войти по коду:  введите 8-символьный код приглашения.
  Пригласить:     скопируйте код из карточки группы и отправьте
                  собеседнику любым удобным способом.

Записи групп зашифрованы (AES-GCM) и подписаны (HMAC-SHA-256)
с ключом, производным от кода приглашения. Код не публикуется
в брокер — только у участников группы.


Звонки
------
  Начать звонок: кнопка «Начать звонок» на карточке группы.
                 Все участники получат входящий звонок.
  Принять:       нажмите «Принять» на оверлее входящего звонка.
  Отклонить:     нажмите «Отклонить» — звонок закроется.
  Сбросить:      кнопка «Завершить» — снимает вызов у всех
                 участников, которые ещё не ответили.

Звонок работает через WebRTC: прямое P2P-соединение между
участниками через STUN-серверы Google и Twilio.


Чат
---
Текстовый чат доступен внутри группы. Сообщения зашифрованы тем
же ключом, что и запись группы, и хранятся как retained-топики
в MQTT (последние 60 сообщений).


Структура файлов
----------------
  rupor.html              — единственный файл приложения
  manifest-rupor.json     — манифест PWA
  rupor-192.png           — иконка 192×192
  rupor-512.png           — иконка 512×512
  rupor-maskable-512.png  — maskable-иконка 512×512
  rupor-shot-wide.png     — скриншот для магазина PWA
  rupor.ico               — иконка для Windows
  Рупор.exe               — лаунчер (открывает rupor.html в Chrome)
  Рупор.vbs               — альтернативный лаунчер

Исходный код (не нужен для запуска, только для разработки):
  C:\Temp\opencode\social.js       — аккаунты, группы, чат, звонки
  C:\Temp\opencode\social-ui.js    — интерфейс групп, чата и звонков
  C:\Temp\opencode\signalling.js   — WebRTC и MQTT
  C:\Temp\opencode\embed-social.js — сборка rupor.html из исходников


Пересборка
----------
После изменения исходников запустите:

  node "C:\Temp\opencode\build.js"

Это встроит social.js и social-ui.js в rupor.html, проверит
синтаксис, запустит все тесты и обновит ZIP-архив.


Технические детали
------------------
  Сигнализация:  два публичных MQTT-брокера (broker.emqx.io и
                 test.mosquitto.org), QoS 1 с retained-сообщениями.
  WebRTC:        STUN stun.l.google.com, stun1.l.google.com,
                 global.stun.twilio.com (без TURN).
  Шифрование:    Web Crypto API — AES-GCM 256 бит для данных,
                 HMAC-SHA-256 для подписи записей групп.
  Хранилище:     только localStorage, никаких cookies и IndexedDB.
